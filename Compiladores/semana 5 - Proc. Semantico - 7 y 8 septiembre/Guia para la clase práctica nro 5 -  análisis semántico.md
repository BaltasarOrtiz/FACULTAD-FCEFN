**Guia para la clase práctica nro 5 \-  análisis semántico**

**Objetivo**  
Introducir al alumno en la etapa del compilador denominada análisis semántico.   
**Objetivo Específicos**

* Que el estudiante comprenda en qué consiste la etapa del compilador correspondiente al análisis semántico  
* Identificar la tecnicas y metodos utilizados por el compilador  para realizar el análisis semántico de un programa

**Desarrollo de clase práctica**

* Vea detenidamente el video de la clase correspondiente al procesamiento semántico  
* Utilizando la herramienta COMPI que se descarga del repositorio de github [https://github.com/CompiladoresExactasUNSJ/compi2026](https://github.com/CompiladoresExactasUNSJ/compi2026)  
* Compile y ejecute el código para asegurarse que funciona bien  
* Dado el video denominado  proc semant parte 2  realice un programa para la herramienta COMPI que permita realizar el seguimiento a nivel de código de la expresión x=3\*(2+4) . Realice el seguimiento a nivel de código  
   1\) identifique los métodos que implementan los símbolos no terminales de la gramática que permite definir este tipo de expresiones  
  2\) para cada método que implementa la parte de la gramática que permite definir expresiones identifique    
  1. atributos de salida y atributos de entrada  
  2. acciones semánticas
