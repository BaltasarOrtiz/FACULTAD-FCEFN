1. Caja de herramientas

1.1 Notación: «mayores potencias a la derecha»

En los parciales, una cadena de bits b0 b1 b2 … bn−1 es el polinomio b0 + b1x + b2x² + … + bn−1xⁿ⁻¹: el primer bit es x⁰.

Ejemplo (2025): 11010001101 → posiciones con 1: 0, 1, 3, 7, 8, 10 → 1 + x + x³ + x⁷ + x⁸ + x¹⁰.

Regla para no perder puntos

Mantené una sola convención. Para dividir a mano conviene escribir el polinomio con la mayor potencia a la izquierda (invertí la cadena del enunciado); al final volvé a la convención del enunciado para escribir resultados. En este apunte las tablas de división están así y se aclara en cada una.

1.2 Aritmética módulo 2

Suma = XOR (0+0=0, 0+1=1, 1+1=0); producto = AND. Restar es lo mismo que sumar. Sumar dos polinomios = XOR bit a bit de sus cadenas. En una división polinómica, cada paso es un XOR del divisor desplazado.

1.3 Parámetros del código

  • n: longitud de la palabra · k: bits de información · n−k: chequeadores (bits de control). Hay 2k palabras válidas entre 2n posibles.
  • Redundancia (como la usa la cátedra) = n/k; cuanto más cerca de 1, mejor. Tasa = k/n.
  • Código lineal: suma de dos palabras válidas es válida. Entonces dmin = peso mínimo de una palabra válida no nula (la distancia entre dos palabras es el peso de su suma, que también es válida).

1.4 Capacidad del código

Con distancia mínima dmin: corrige t errores con dmin ≥ 2t+1, es decir t = ⌊(dmin−1)/2⌋; como detector puro detecta dmin−1. Si se usa a la vez para corregir t y detectar hasta s ≥ t: dmin ≥ t+s+1.

Propiedades de g(x) (teórica fija del parcial)
  1. g(x) es de grado n−k.
  2. g(x) es factor de xⁿ+1.
  3. Tiene coeficiente 1 en el término independiente y en el de mayor grado.
  4. Es el polinomio de menor grado del código (y primo, según la cátedra).

Atajo de validez: un polinomio no nulo de grado menor que n−k nunca es palabra válida (no puede ser múltiplo de g).

2. ISBN y base prima (Etapa 1)

2.1 Receta ISBN-10 con un dígito desconocido

Receta (código «pesado», base 11)
  1. Escribí los 10 dígitos y marcá el desconocido ?. El símbolo de control (posición 10) puede ser X = 10.
  2. Pesos: 10, 9, 8, …, 1 (la posición 1 pesa 10; la 10 pesa 1).
  3. Calculá dígito × peso y sumá los conocidos: S.
  4. Con el peso w de la posición del ?: resolvé S + w·x ≡ 0 (mod 11), o sea x ≡ −S·w⁻¹ (mod 11).
  5. Verificá: la suma total debe ser múltiplo de 11. Si da 10 solo vale como X en el verificador.

Inversos módulo 11 (para no calcular cada vez): 1→1, 2→6, 3→4, 4→3, 5→9, 6→2, 7→8, 8→7, 9→5, 10→10.

2.3 Capacidad del código ISBN y base prima (teóricas fijas)

Capacidad del ISBN
  • dmin = 2: detecta un error (si cambia un solo dígito, la suma cambia en w·δ ≠ 0 mod 11 y deja de ser múltiplo de 11). Como los pesos son todos distintos, también detecta el intercambio de dos dígitos adyacentes.
  • No corrige: sabe que algo falló pero no dónde. Solo se corrige con una hipótesis (p. ej. «el erróneo es el verificador» o «sé cuál posición está mal», como en los ejercicios con ?).
  • Dos errores que se compensan pasan inadvertidos: el código resultante es válido pero corresponde a otro libro (error indetectable).
¿Por qué base prima? (2012 T2 y 2020)

Para decodificar hay que resolver w·x ≡ c (mod b). Si la base b es prima, cualquier peso w ≠ 0 tiene inverso y la solución es única: no hay ambigüedad al decodificar (la cátedra: «la base prima garantiza unicidad en el proceso de decodificación»).

Contraejemplo con base 10: 2x ≡ 4 (mod 10) tiene dos soluciones, x = 2 y x = 7. Con base 11, 2x ≡ 4 → x = 2 y nada más.

Base 37 (diapositiva 9)

Para códigos alfanuméricos (0–9, A–Z, espacio = 37 símbolos) se usa base 37 sin pesos por posición: se suman los valores de los caracteres y el verificador completa a múltiplo de 37. Ejemplo de la diapositiva: AZ9-? → 10 + 35 + 9 = 54; (54 + ?) mod 37 = 0 → ? = 20 = K.

3. Hamming y arreglos geométricos (Etapas 2 y 3)

3.1 Hamming (7,4)

Posiciones 1 a 7: C1 C2 I1 C3 I2 I3 I4. Los chequeadores ocupan las posiciones potencia de 2 (1, 2, 4). Cada síndrome mira las posiciones cuya numeración binaria tiene un 1 en ese bit:

  • S1 = C1 ⊕ I1 ⊕ I2 ⊕ I4 (posiciones 1, 3, 5, 7)
  • S2 = C2 ⊕ I1 ⊕ I3 ⊕ I4 (posiciones 2, 3, 6, 7)
  • S3 = C3 ⊕ I2 ⊕ I3 ⊕ I4 (posiciones 4, 5, 6, 7)

(S3 S2 S1) en binario = posición del error; si es 000 no hay error. dmin = 3 → corrige 1, detecta 2. Es un código perfecto: 23 = 8 = 1 + 7 (cada síndrome sirve a una posición o a «sin error»).

Ejemplo completo

Codificar I1I2I3I4 = 1 0 1 1: C1 = I1⊕I2⊕I4 = 1⊕0⊕1 = 0; C2 = I1⊕I3⊕I4 = 1⊕1⊕1 = 1; C3 = I2⊕I3⊕I4 = 0⊕1⊕1 = 0. Palabra: 0 1 1 0 0 1 1.

Canal cambia la posición 6: recibido 0 1 1 0 0 0 1.

Decodificar: S1 = r1⊕r3⊕r5⊕r7 = 0⊕1⊕0⊕1 = 0; S2 = r2⊕r3⊕r6⊕r7 = 1⊕1⊕0⊕1 = 1; S3 = r4⊕r5⊕r6⊕r7 = 0⊕0⊕0⊕1 = 1. (S3S2S1) = 110 = 6 → se invierte la posición 6 → 0110011 ✓.

4. Códigos cíclicos: el corazón del parcial (Etapas 4–7)

Receta general (aplica a TODOS los parciales)
  1. k = grado de h(x); chequeadores = n − k.
  2. g(x) = (xⁿ+1) / h(x) por división polinómica (resto 0).
  3. dmin: listá las 2k−1 palabras no nulas V = m(x)·g(x) y tomá el peso mínimo. Atajo: dmin ≤ #términos de g.
  4. Capacidad: t = ⌊(dmin−1)/2⌋; detecta dmin−1.
  5. Matriz generadora: sistemática G = [P | Ik] con la fila i de P = (xn−k+i mod g). O sin sistematizar: filas = g(x), x·g(x), x²·g(x), …
  6. Matriz chequeadora: H = [In−k | PT]. Comprobá G·HT = 0.
  7. Chequeadores: la columna j de P dice qué bits de información suma el chequeador cj.
  8. Decodificar: r(x) = R(x) mod g(x). r = 0 ⇒ válida. Si no, buscá el patrón de error e de peso ≤ t con e mod g = r y corregí V = R ⊕ e.
  9. Circuito: registro de k celdas realimentado según h(x).
  10. Entrelazado: con L palabras entrelazadas se corrigen ráfagas de t·L bits.

Paso 6 · Errores dobles y triples (2020, inciso E)

Cómo se decodifica en general: se divide R(x) por g(x); el resto es el síndrome. Se lo compara con las filas de HT (= columnas de H = síndromes de errores simples): una coincidencia → error simple en esa posición; la suma (XOR) de dos filas → error doble en esas dos posiciones; etc.

Error triple: como t = 2, el decodificador solo busca patrones de peso ≤ 2. Con 3 errores el síndrome es el XOR de 3 filas de HT y no coincide con ninguna fila ni con ningún XOR de dos filas: el error se detecta (síndrome ≠ 0) pero no se corrige (hay que pedir retransmisión). Esto nunca se confunde con un error corregible: si un patrón de peso ≤ 2 diera el mismo síndrome, la diferencia entre ambos patrones sería una palabra válida de peso ≤ 5 < 6 = dmin, que no existe.

Ejemplo: palabra válida 111111111111 con errores en las posiciones 0, 1 y 2 → resto 111000000 (es el XOR de las filas de x⁰, x¹ y x²). Como no coincide con ninguna fila de HT ni con la suma de dos de ellas, se detecta sin corregir.

Si en cambio hubiera 2 errores, el síndrome es el XOR de dos filas de HT (y es único: lo verifiqué para todos los patrones de peso ≤ 2) → se corrigen.

Hay dos arquitecturas (Fibonacci y Galois, esta última es la usada en control de error); como h(x) de este código es palíndromo, el dibujo no cambia entre ambas. 5. Entrelazado y ráfagas (Etapa 7)

Los códigos de bloque están pensados para errores aleatorios (independientes). Una ráfaga (errores en bits consecutivos por una causa común: un rayón en un CD, un desvanecimiento) puede superar la capacidad t de una sola palabra.

Entrelazar L palabras: se escriben las L palabras como filas de una matriz y se transmite por columnas (primer bit de la palabra 1, primer bit de la palabra 2, …, primer bit de la palabra L; después los segundos bits…). Si el canal daña una ráfaga de B bits consecutivos, cada palabra recibe como máximo ⌈B/L⌉ errores. Se puede corregir si ⌈B/L⌉ ≤ t, es decir:

Ráfaga corregible = t · L bits  (y detectable: (dmin−1)·L)

7. Teóricas de control de error con respuesta

1. Si se entrelazan n códigos, ¿qué nuevas capacidades adquiere el código?
Corrige ráfagas de longitud t·L (t = capacidad de corrección por palabra, L = cantidad de palabras entrelazadas); también multiplica por L la longitud de ráfaga detectable. No cambia t ni la tasa k/n. Ver sección 5.

2. Propiedades del polinomio generador de un código cíclico.
(1) es de grado n−k; (2) es factor de xⁿ+1; (3) coeficiente 1 en el término independiente y en el de mayor grado; (4) es el de menor grado y primo; (5) toda palabra válida es múltiplo de g(x) y todo múltiplo de g(x) (grado menor que n) es palabra válida; (6) toda rotación de una palabra válida es otra palabra válida.

3. ¿Qué relación tienen G y H? ¿Qué significa?
Son ortogonales: G·HT = 0. Si G = [I | P] entonces H = [PT | I]; si G = [P | I] entonces H = [I | PT]. Toda palabra válida pertenece al subespacio generado por las filas de G, y H genera el subespacio perpendicular: el producto escalar de una palabra válida por cada fila de H da 0; si hubo error, el síndrome S = R·HT es ≠ 0 y coincide con la suma de las columnas de H en las posiciones erróneas.

4. ¿Un código cíclico de capacidad 10 (dmin = 10), qué puede hacer?
Como corrector: dmin ≥ 2t+1 → t = 4, corrige hasta 4 (y detecta 5 a la vez). Como detector: detecta dmin−1 = 9.

5. Capacidad de un código ISBN.
dmin = 2: detecta un error en una sola posición (y el intercambio de dos dígitos adyacentes en ISBN-10); no corrige. Dos errores que se compensan producen otro ISBN válido: error indetectable.

6. ¿Cómo se calcula el dígito faltante de un ISBN?
Pesos 10…1, suma de dígito × peso ≡ 0 (mod 11); resolver w·x ≡ −S (mod 11). Ver sección 2.

7. Necesidad de la base prima.
Con base prima todo peso no nulo tiene inverso, así que la ecuación de decodificación w·x ≡ c tiene solución única: no hay ambigüedad al decodificar.

8. ¿Por qué dmin ≥ 2t+1?
Para corregir t errores, las «esferas» de radio t alrededor de cada palabra válida no deben superponerse: dos palabras a distancia ≥ 2t+1 dejan cada palabra recibida a lo sumo a distancia t de una sola. Como detector basta dmin−1 porque ninguna combinación de ≤ dmin−1 errores convierte una palabra válida en otra.

9. ¿Qué sucede en la decodificación con más errores de los que corrige el código?
Si el patrón tiene peso ≤ dmin−1 el síndrome es ≠ 0 y se detecta (no se corrige); con peso mayor el patrón puede coincidir con otra palabra válida y no detectarse, o ser «corregido» al lado equivocado.

10. ¿Qué distancia mínima tiene un arreglo rectangular?
dmin = d1·d2 (producto de las distancias del código por filas y del código por columnas). Ver 3.2.

10. Chuleta de una página

Capacidad

t = ⌊(dmin−1)/2⌋ · detecta dmin−1 · mixto: dmin ≥ t+s+1
Lineal: dmin = peso mínimo de palabra no nula.
Cíclico: dmin ≤ #términos de g.

Cíclicos

k = grado h · n−k = grado g · g = (xⁿ+1)/h
V = i·g (no sist.) · V = xⁿ⁻ᵏ·i + r (sist.), r = xⁿ⁻ᵏ·i mod g
Decodificar: r = R mod g; r = 0 válida; si no, e (peso ≤ t) con e mod g = r; V = R+e.
Grado(R) < n−k y R ≠ 0 ⇒ no válida (resto = R).

Matrices

G = [P | I] con fila i de P = xn−k+i mod g
H = [I | PT] · G·HT = 0
Si G = filas g, xg, x²g…, H = desplazamientos del recíproco de h.
Chequeador j = suma de los im con P[m][j] = 1.
Síndrome = suma de columnas de H en las posiciones erróneas.

Entrelazado

Ráfaga corregible = t·L · detectable = (dmin−1)·L

Hamming (7,4)

C1 C2 I1 C3 I2 I3 I4 · S1: pos 1,3,5,7 · S2: 2,3,6,7 · S3: 4,5,6,7
(S3S2S1)2 = posición del error · dmin = 3
+ BP: dmin = 4 · S≠0 y BP falla → corrige · S≠0 y BP ok → doble.

Arreglos

dmin = d1·d2 · falla fila + falla columna → error en la intersección.
